# 标签页定时刷新（Chrome 扩展 · Manifest V3）

给任意标签页设置定时自动刷新。刷新任务在浏览器后台运行，最小化窗口、切换标签页都不影响；浏览器重启后任务自动继续。

## 安装方法

1. 解压本压缩包，得到 `tab-auto-refresh` 文件夹（路径中尽量不要包含特殊字符）。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的「开发者模式」开关。
4. 点击「加载已解压的扩展程序」，选择 `tab-auto-refresh` 文件夹。
5. 建议把扩展图标固定到工具栏（拼图图标 → 图钉）。

## 使用方法

### 方式一：点扩展图标
1. 打开想要定时刷新的网页，点击工具栏的扩展图标。
2. 选择刷新间隔（30 秒 / 1 分钟 / 2 分钟 / 5 分钟 / 10 分钟 / 30 分钟 / 1 小时），或在输入框里填自定义秒数（不少于 30 秒）。
3. 点击「开始定时刷新当前标签页」。按钮变红表示正在运行，再点一次即停止。
4. 弹窗下方会列出所有正在定时刷新的标签页，带倒计时，可随时「立即刷新」或「取消」。

### 方式二：右键标签页
在浏览器顶部的标签页上点右键 → 「标签页定时刷新」→ 选择一个间隔即可开启，或选「停止定时刷新」。

## 选项说明

- **刷新时忽略缓存**：默认开启，相当于按 Ctrl+F5，确保拿到服务器最新内容；关闭后走普通刷新（更快、省流量）。
- **工具栏角标数字**：表示当前有几个标签页正在定时刷新。

## 注意事项

- 间隔下限是 30 秒：Chrome 的 alarms 定时机制不允许更短的周期，更短的间隔会被浏览器放慢。
- `chrome://`、扩展商店等浏览器内部页面无法被扩展刷新，插件遇到这种情况会自动清理任务。
- 被刷新的标签页如果处于「休眠」状态，到点会被唤醒并加载，正好可以防止标签页休眠。
- 关闭对应标签页后，该标签页的定时刷新任务自动删除。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| manifest.json | 扩展清单（MV3、权限声明） |
| background.js | 后台 service worker：定时器、刷新、角标、右键菜单 |
| popup.html / popup.css / popup.js | 点击图标弹出的操作界面 |
| icons/ | 扩展图标 |
